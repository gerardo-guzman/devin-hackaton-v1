# devin-hackaton-v1

> Repositorio oficial de nuestra hackathon. Todavía no sabemos qué estamos construyendo, pero va a ser épico.

## ¿Qué es esto?

Honestamente? Buena pregunta. Este repo nació con más entusiasmo que planificación, como todo buen proyecto de hackathon. Lo importante es que estamos aquí para divertirnos, romper cosas y (con suerte) que algo compile al final del día.

## La idea

```
[ ] Definir qué vamos a hacer
[ ] Elegir el stack (pelea pendiente)
[ ] Escribir código que funcione
[ ] Escribir código que funcione *bien* (opcional)
[ ] Dormir (muy opcional)
```

## Cómo correrlo

Cuando haya algo que correr, las instrucciones van a vivir acá. Por ahora:

```bash
# Paso 1: clonar el repo
git clone <url-del-repo>

# Paso 2: abrirlo
cd devin-hackaton-v1

# Paso 3: manifestar que el código se escriba solo
# (resultados pueden variar)
```

## Reglas no escritas (pero ahora escritas)

1. Si compila, se commitea.
2. No se juzga código escrito después de las 2 AM.
3. "Funciona en mi máquina" es una respuesta válida.
4. El que rompe `main`, trae los snacks.
